# Plugin Modernizer Stats Visualization

A public, static visualization platform for Jenkins plugin modernization data.

This project consumes structured metadata generated by the Jenkins plugin-modernizer tool from the `jenkins-infra/metadata-plugin-modernizer` repository and presents it through intuitive dashboards, data explorers, and per-plugin reports.

---

## 🚀 Features

- Ecosystem-wide dashboards for plugin modernization status  
- Visualization of key areas:
  - Parent POM upgrades  
  - BOM alignment  
  - Deprecated API usage  
  - Test framework migration  
- Plugin-level detailed reports with actionable insights  
- Search, filtering, and sorting capabilities  
- Data export support (CSV/JSON)  

---

## 🛠️ Tech Stack

- React + TypeScript (Vite)  
- Apache ECharts (data visualization)  
- Static site architecture (no backend)  
- GitHub Actions (CI/CD)  

---

## 📊 Data Source

- `jenkins-infra/metadata-plugin-modernizer` (CSV/JSON datasets)

---

## 🎯 Goal

To improve visibility into Jenkins plugin modernization efforts and help maintainers and contributors identify high-impact improvements, prioritize upgrades, and enhance ecosystem health.
